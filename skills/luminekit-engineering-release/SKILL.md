# Prepare or perform an engineering release

Use the [luminekit-workflow](../luminekit-workflow/SKILL.md) skill if its instructions are not already loaded. Reuse current task state, then continue within this skill’s scope.

Resolve preparation versus each requested effect, repository/environment, outgoing revision/dirty scope, targets and current review/check evidence. A PR body or readiness assessment can be the complete requested product.

| Concern | Procedure |
| --- | --- |
| Actual engineering operation, retry or action authority | [Action authority](references/action-authority.md) |
| Source/check/artifact readiness, including before an effect | [Readiness](references/readiness.md) |
| Push, PR wording, creation/update or merge | [Push and PR](references/push-and-pr.md) |
| Actual Azure DevOps operation through available git/az | [Azure DevOps](references/azure-devops.md) |
| Deployment or stateful migration | [Deployment](references/deployment.md) |

Resolve exact targets/payloads and real prerequisites immediately before each effect; do not infer additional operations from readiness. Report the prepared product or actual per-item results, matching evidence, held work and next safe step. Mocks and documentation do not establish live-provider support.
