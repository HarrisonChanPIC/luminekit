# Azure DevOps through existing tools

Check installed tool/extension presence before using current help. Azure's `az repos pr` and `az boards work-item` commands can auto-install a missing extension; invoking them is not an installation-free probe. Preparation needs neither sign-in nor persistent-default changes.

Resolve actual organization, project, repository, refs and item/PR identities. Prefer supported explicit per-command targeting over ambient detection and verify returned ownership. Commands differ: documented PR creation accepts organization/project/repository/branch arguments, while PR show/update and work-item show/update use IDs plus organization/detection. Inspect installed help rather than inventing project/repository flags. The [push/PR procedure](push-and-pr.md) owns the exact-revision limitation.

Git push and PR creation are separate operations. Use the organization's actual branch/review policy and work-item field reference names, types and states. Discussion, fields, state and relations are distinct mutations; a discussion grant does not authorize a state transition. For comment readback, verify the selected API/version, pagination, coverage and request correlation. A work-item snapshot or matching text is not complete comment history, and CLI discussion updates need not share an implementation with a documented REST endpoint.

Read only the selected operation's current official surface: [DevOps CLI](https://learn.microsoft.com/en-us/azure/devops/cli/?view=azure-devops), [PR commands](https://learn.microsoft.com/en-us/cli/azure/repos/pr?view=azure-cli-latest), [work-item commands](https://learn.microsoft.com/en-us/cli/azure/boards/work-item?view=azure-cli-latest), [Git push](https://learn.microsoft.com/en-us/azure/devops/repos/git/pushing?view=azure-devops), [fields](https://learn.microsoft.com/en-us/azure/devops/boards/work-items/work-item-fields?view=azure-devops), [comments](https://learn.microsoft.com/en-us/rest/api/azure/devops/wit/comments/get-comments). Documentation does not establish tenant compatibility, installed capability or company policy.
