# Release input readiness

Identify the exact requested release snapshot: checkout, base/stack parent where relevant, outgoing committed range, dirty/untracked contributions, generated outputs and target. Match review, required checks and approval to those inputs. If a grant requires the reviewed snapshot and current source differs, hold that publication; do not reset user work or create a commit to manufacture a match. A separately approved independent operation can still proceed.

Use [engineering verification](../../luminekit-engineering-change/references/verification.md) for built-source correspondence and the evidence boundary. Check current findings, required gates and target policy before the effect. Prepare the exact supported revision/target, completed evidence, held action and missing prerequisite when readiness is incomplete. Exclude credentials, live tokens and broad transcripts from the packet.
