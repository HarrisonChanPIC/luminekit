# Configure a usable project

Follow the `luminekit-workflow` skill within this skill’s scope.

Use [project choices](references/project-choices.md) to inspect existing conventions, ask only unresolved consequential questions and apply or propose the selected setup. Preserve established choices on rerun. Installation alone ends after installation/verification.

An applied setup leaves the chosen workspace usable, a small project catalog reachable and the chosen human attribution alias or omission recorded by augmenting existing agent instruction surfaces. Creating `AGENTS.md`, `CLAUDE.md` or another native instruction file requires an explicit user request; selecting a harness does not request file creation. Preserve unrelated instructions and keep maintained knowledge usable without ignored scratch.

Use the catalog procedure of `luminekit-docs` for project vocabulary and standard OKF conventions. That skill also owns source-backed authoring, consumption, navigation and bounded documentation migration. Call only the procedure needed; ordinary documentation work does not restart setup.

Deliver chosen locations, catalog and entry routes, recorded attribution choice, actual checks and unresolved decisions. Distinguish configured files from observed automatic harness loading. Plan-only work returns the proposal without creating directories or changing instructions.
