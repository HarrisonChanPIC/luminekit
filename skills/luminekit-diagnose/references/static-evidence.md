# Diagnosis without execution

Current sources can establish a bounded cause when execution is unavailable or outside scope. State the independent requirement, causal source path and remaining uncertainty. Inspection or arithmetic is not runtime reproduction.

Propose a discriminating observation of the **unchanged current subject**: the actual function/entry/artifact, concrete relevant input, independent expected outcome, and what the diagnosis predicts. Use a known invocation when available; otherwise identify the needed observation and missing entry/access. Mark it unperformed. A hypothetical future suite or “verify after fixing” does not provide this diagnostic check.

Keep that observation separate from a proposed remedy and verification of the changed artifact. Testing a remedy answers whether it works; it cannot retrospectively reproduce the original state. Return the supported conclusion, proposed current-state check, remedy if useful and remaining limit without claiming a performed fix.
