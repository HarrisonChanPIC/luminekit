# Author and use focused knowledge

Follow the `luminekit-workflow` skill within this skill's scope. Establish the reader's actual question and authorized output. Reading or a proposal stays read-only; missing project preferences do not require setup before an ordinary documentation task.

Inspect current entries, owners and supporting sources. If an accurate, discoverable, appropriately focused route already serves the task, verify it and return no change. Write supported knowledge rather than an empty skeleton; distinguish intended behavior from observed implementation.

| Reader task | Procedure |
| --- | --- |
| Consume an OKF concept or bundle | [OKF reading](references/okf-reading.md) |
| Produce or revise an OKF concept | [OKF authoring](references/okf-authoring.md) |
| Establish or extend a small project catalog | [Catalogs](references/catalogs.md) |
| Author missing knowledge from requirements, code or business records | [Source-backed authoring](references/source-backed-authoring.md) |
| Choose focused owners, extract mixed tasks or repair navigation | [Owners and navigation](references/owners-and-navigation.md) |
| Apply an authorized replacement, move or removal | [Migration and application](references/migration-and-application.md) |

Keep entries to brief orientation, frequently needed facts and conditional routes. Put independent task guidance in focused owners regardless of file size. Preserve complete procedures, exceptions, effective periods, source identities and useful rationale. Current guidance must work without ignored work history. A shorter file or green metadata check alone establishes no retrieval benefit.

For upkeep after a confirmed change or selective closeout, use `luminekit-docs-maintain`. For a documentation audit, meaning-preservation comparison or reading-cost claim, use `luminekit-docs-review`. Project workspace, attribution and harness configuration belong to `luminekit-setup`.

Deliver the supported answer, authored owners/routes or proposal, with source basis, actual preservation/retrieval checks and remaining gaps. Load only the relevant procedure and necessary dependencies.
