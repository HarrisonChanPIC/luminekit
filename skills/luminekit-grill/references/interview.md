# Conduct the interview

## Ground the questions

Establish the objective, the next action this interview should enable, existing agreements and material uncertainty. Reuse what the user and available sources already establish. When the purpose itself is unclear, ask an open question before proposing choices that could steer it.

Investigate discoverable facts in the relevant source, code or records. Separate current behavior from intended behavior. An unavailable fact remains unknown; a decision belonging to someone else stays pending with its owner identified. Ask the user for their intent or a choice they can make, rather than asking them to retrieve accessible facts or decide on another person's behalf.

## Sequence the decisions

Identify consequential choices and which answers or facts each needs. Ask only questions whose prerequisites are settled. While a fact is being investigated, unrelated answerable questions can proceed; dependent questions wait.

Use manageable rounds, prioritizing the decisions that unblock the next action. Give each question a clear focus. Where feasible choices are known, include a recommendation and the meaningful tradeoff; keep the recommendation distinct from the user's decision. Use the harness's available question interface or numbered questions in the reply.

Wait for answers before building on them. Carry accepted decisions forward and revise the remaining questions after each round. Partial replies settle only the points they actually answer. A suggestion, silence or the existence of a preselected option is not acceptance.

## Test the meaning

For vague or overloaded language, distinguish the concepts with a concrete boundary scenario and propose precise terms. Test whether the same words imply different outcomes for different people, states or events. When the user's intent conflicts with existing code or records, show the relevant behavior and its consequence, then resolve which expectation should govern.

## Close at the useful boundary

Stop when the consequential ambiguity for the selected next action is sufficiently resolved, or when the user ends or redirects the interview. Further possible topics do not expand that boundary automatically.

Return a concise account of the clarified intent, accepted choices and any remaining proposals, unknowns or deferred decisions that affect the next action. Invite correction where understanding remains uncertain, without adding a blanket approval gate.
