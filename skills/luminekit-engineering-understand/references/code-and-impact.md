# Code, rationale and impact

Trace the selected entry through inputs, transformations, state changes, outputs and error behavior. Read the relevant contracts, configuration and actual consumers when behavior crosses storage, wire formats, flags or runtime boundaries; symbol matches alone may miss them. Cite verified files/symbols and locations.

For an impact question, identify affected callers, data, compatibility and required checks. Distinguish consumers reached by the traced path from similar-looking code elsewhere. Name assumptions that would change the conclusion and a useful way to check them.

For a rationale question, inspect available decisions, history, issues or comments. Separate recorded intent from inferred motivation; current behavior cannot establish why an author chose it. An unavailable history category limits that explanation, rather than proving no rationale exists. Retain material contradictions between recorded intent and implementation.
