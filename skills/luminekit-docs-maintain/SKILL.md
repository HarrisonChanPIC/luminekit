# Maintain current knowledge

Follow the `luminekit-workflow` skill within this skill’s scope.

Update the existing owner after a confirmed change, reconcile current/proposed knowledge, or transfer useful value before authorized retirement. Inspect the affected source/change evidence and open work; correct current docs do not by themselves finish pending closeout.

Preserve focused owners and concise routes during ordinary updates. Place independently needed additions in their task owner before expanding an entry; keep contextual history and work evidence outside current guidance. [Owner updates](references/owner-updates.md) applies the shared placement procedure.

| Work | Procedure |
| --- | --- |
| Promote/reconcile changed facts, future terms or current/proposed state | [Owner updates](references/owner-updates.md) |
| Transfer rationale/open work and retire selected scratch | [Selective closeout](references/closeout.md) |
| Reassess an affected witness or adopted structural exception | Structure-and-evidence procedure of the `luminekit-docs-review` skill |
| Measure an expensive reading path or claimed reduction | Reading-cost procedure of the `luminekit-docs-review` skill |
| Capture otherwise missing state at a real boundary | Capture procedure of the `luminekit-continue` skill, plus its recipient-access procedure for another reader |

Read back updated owners and affected routes against complete source propositions. Verify durable transfer before removing the sole useful scratch source. Retire only authorized disposable material; preserve controlled originals and unresolved value. Deliver actual updated/removed/held paths, retained rationale/open work, recovery disposition and material limits.
