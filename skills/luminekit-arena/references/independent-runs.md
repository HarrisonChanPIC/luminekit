# Frame independent Arena contexts

Use the delegation and independent-work procedure of `luminekit-workflow` for capabilities, bounded assignments, context isolation, collection and acceptance. This procedure owns Arena's candidate, reviewer and judge framing.

## Before dispatch

Fix independent recommendation versus design exploration before outputs. Use the [candidate brief](../assets/candidate-brief.md), or reuse an equivalent one, with the common controlling basis. Give fresh candidates neutral problem/constraint grounding without a preferred design, sibling answers, conversational reasoning or private evaluator conclusions. Implementation assignments following a selected design are not independent design candidates.

Use fresh independent reviewer contexts with original requirements distinct from candidate-authored artifacts, applying Workflow's targeted-verification limits.

## Judge completed outputs

Use Workflow's shared judge timing, fresh-context and neutral-input safeguards. Prefer a judge that did not author a candidate when the permitted pool allows; disclose reduced independence otherwise. Frame its question using the chosen Arena purpose and return actual briefs, output/context identities and known execution limits to [comparison and synthesis](comparison-and-synthesis.md).
